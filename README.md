# Rosario+Vampire DS — русская локализация

Полный русский перевод **Rosario to Vampire: Tanabata no Miss Youkai Gakuen**
(Nintendo DS). Базовая версия — английский фан-патч jjjewel.

Репозиторий содержит **только перевод, инструменты и документацию**.
ROM, шрифтовые бинарники и скриншоты игры не распространяются: всё собирается
из собственной легальной копии.

## Что готово

- 13 858 строк диалогов (9 MPC-файлов) переведены и вставлены.
- Кириллица (66 глифов) встроена в игровой `#FNT`-шрифт.
- Переносы строк пересчитаны под ширину текстового бокса (228 px).
- Собран и проверен ROM `Rosario_RU_v4.nds` (в репозиторий не входит).

Ограничения: таблички имён спикеров («Girl», «Kotori») остаются латиницей;
меню (Start/Gallery/Options) — отдельные контейнеры, не переводились;
часть длинных строк сокращена редактурой.

## Структура

```
translation/       русские тексты 000.txt…008.txt + глоссарий
tools/             сборка шрифта, упаковка MPC, сборка ROM
font/cyr_slots.tsv карта «буква → слот глифа»
tools/rosario.tbl  таблица кодировки (код ↔ символ)
docs/ENGINEERING.md форматы и детали реверса
```

## Сборка

Нужны: Python 3 (Pillow, ndspy), оригинальный ROM (английская версия)
в корне как `rosario_eng.nds`.

```bash
python tools/extract_mpc.py           # ROM -> work/orig_mpc/*.mpc
python tools/prepare_txt.py           # translation/ -> extracted/mpc
python tools/pack_ru_mpc.py           # -> extracted/mpc/*_ru.mpc
python tools/build_cyr_font7_thin.py  # -> font/font_all_ru7.fnt
python tools/build_rom_v4.py          # -> roms/Rosario_RU_v4.nds
```

`tools/ru_shorten.py` — редакторские сокращения длинных строк (не обязателен
для сборки, если тексты уже сокращены).

## Форматы (кратко)

- **BB** — архив: `u32 count` + пары `(offset,size)`; записи могут быть LZ10.
- **MPC** — текстовый контейнер: таблицы `LC/LL/DS`, строки — u16-коды;
  поток кодов упакован 3↔4 байта (`tools/mpc_codec.py`).
- **#FNT** — 3387 глифов 16×16: четыре тайла 8×8, 4bpp, младший ниббл слева,
  `1` тело, `2` тень; таблица глифов `(u16 0, u16 len, u32 offset)`,
  ширины по 1 байту на глиф.
- LZ10-декодер игры копирует ссылки по 2 байта: **disp = 1 недопустим**,
  компрессор обязан держать disp ≥ 2.

Подробности — [docs/ENGINEERING.md](docs/ENGINEERING.md).
