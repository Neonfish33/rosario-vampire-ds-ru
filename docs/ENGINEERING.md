# Форматы и реверс-инжиниринг

Документ описывает форматы, восстановленные для перевода
Rosario to Vampire: Tanabata no Miss Youkai Gakuen (NDS).

## Контейнеры

### BB
```
0x00 "BB\0\0" (0x42420000)
0x04 u32 file_count
0x08 count × (u32 absolute_offset, u32 size)
```
Записи могут быть LZ10-сжаты (первый байт `0x10`).

### NARC
Стандартный NARC: `BTAF` (таблица файлов), `BTNF` (имена), `GMIF` (данные).
Часть NARC в ROM сжата LZ10.

### MPC (текст)
```
0x00 "MPC\0"
0x0A u16 string_count
0x0C u16 string_count
0x0E u16 total_line_count
0x10 u32 0x20          ; offset таблицы указателей
0x14 u32 LC offset     ; (u16 lines, u16 str_index) × string_count
0x18 u32 LL offset     ; длины линий (u32 на линию)
0x1C u32 data offset
0x20     string_count × (u16 kind=1, u16 str_index, u32 start_code)
```
- `start_code` — накопительное смещение в **кодах** (код = 2 байта).
- LL: для одной линии — `u32 len1`; для двух — `u32 len1`, `u32 (len1<<16 | len2)`.
- Данные — поток пар `(code & 0xFF, code >> 8)`, упакованный 3↔4 байта:
  `enc(d0,d1,d2,d3) = (d0, ((d2 & 0xF) << 4) | (d1 & 0xF), ((d3 & 0xF) << 4) | (d2 >> 4))`.
  Паддинг нулями до кратности 4.
- Терминаторы/переносы: `[EL]`=`CD0C`, `[NL]`=`CB0C` (000);
  `[EL2]`=`3D0D`, `[NL2]`=`3B0D` (001–008).

## Шрифт `#FNT`

- 3387 глифов; ширины — 1 байт на глиф, таблица с `0x20`.
- Таблица глифов с `0xD80`: `(u16 0, u16 len, u32 offset)`,
  `len` включает 4-байтный заголовок LZ10.
- Глиф: 16×16, четыре тайла 8×8 **4bpp** (TL, TR, BL, BR),
  младший ниббл — левый пиксель; `1` тело, `2` тень (+1,+1).
- Полуширинные глифы занимают левые тайлы, правые пустые.
- Игра делает «жирнение» (несколько копий со сдвигом), поэтому глифы должны
  быть тонкими (1 px штрих), иначе счётчики букв закрываются.
- **LZ10-декодер игры копирует ссылки по 2 байта: disp = 1 даёт мусор.**
  Компрессор обязан держать disp ≥ 2.
- Офсеты глифов в таблице менять нельзя (иначе данные «переезжают» и вместо
  глифов выводятся фрагменты). Замена блобов — по месту, с правкой `len`/ширины.

## Раскладка текста

- Бюджет строки — 228 px (максимум в оригинале 227).
  Ширина символа = байт из таблицы ширин.
- Перенос: оптимальная точка `[NL2]` + перенос по словам; реализовано в
  `tools/pack_ru_mpc.py` (`rewrap`).
- Многоточие-лидеры (`…`) заменяются на три точки: глиф 0x9C в игре «плавает».

## Кириллица

- 66 глифов (А–Я, а–я, Ё/ё, Й/й) занимают ASCII-слоты; карта —
  `font/cyr_slots.tsv`.
- Часть редких букв посажена в слоты знаков препинания с достаточным размером.
- Таблица кодировки для упаковщика — `tools/rosario.tbl`.

## Ограничения

- Имена спикеров на плашках идут другим потоком — остаются латиницей.
- Меню/галерея — другие контейнеры (графика/MPC в NARC), не переводились.
- Часть строк сокращена редактурой под бюджет ширины.
